# Math Quest — Prealgebra Practice for Advik 🦉

A kid-friendly, rewards-oriented web app that generates a **fresh 15-question
prealgebra practice test every day**, modeled on the AoPS *Math 6: Prealgebra
(Part 1)* "Do You Know?" diagnostic.

## How to use it
Just open **`index.html`** in any web browser (double-click it). No install,
no internet needed — it works fully offline, and all progress is saved right
in the browser.

## What's inside each test
Every test is randomly generated, so the numbers are different each day but the
skills match the real diagnostic:

**Fundamentals** — exponent basics, exponent laws (powers of 2), LCM/GCD,
fraction arithmetic, decimal ↔ fraction conversion, linear equations, ratios & rates.

**Problem Solving** — arithmetic series, expressing products as a power of 4,
divisibility puzzles, digit puzzles, "add to numerator & denominator" fraction
puzzles, work-rate problems, and average-speed (round-trip) problems.

The answer box is forgiving: fractions (`5/8`), mixed numbers (`1 1/12`),
powers (`2^7`), and decimals are all accepted, and units like `dogs`/`mph`/`$`
are ignored.

## Rewards to keep Advik motivated
- ⭐ **Stars** for every correct answer
- 🔥 **10-day streak calendar** counting down to test day
- 🏅 **XP & levels** with a progress bar
- 🎖️ **Badges** (First Test, Perfect Score, streak milestones, Sharp, Level 5)
- 🎊 **Confetti** and encouraging messages, plus a review of every question at the end

> Tip: One test a day for the next 10 days. Wrong answers show a hint and the
> correct solution so Advik can learn from each one.
