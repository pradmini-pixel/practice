# Math Quest — Prealgebra & Algebra Practice 🦉

A kid-friendly, rewards-oriented web app that generates a **fresh 15-question
practice test every day**, covering both the AoPS *Prealgebra* and
*Introduction to Algebra* pre-test material. Every test is randomly generated,
and question types never repeat within a single test.

## How to use it
Just open **`index.html`** in any web browser (double-click it). No install,
no internet needed — it works fully offline, and all progress is saved right
in the browser.

## What's inside each test
Every test is randomly generated, so the numbers are different each day but the
skills match the real diagnostic:

**Fundamentals** — exponent basics & laws, LCM/GCD, fraction arithmetic,
decimal ↔ fraction conversion, linear equations, ratios & rates, **expanding &
simplifying algebraic expressions**, **percents** ("17 is what percent of 20?"),
**complex fractions**, and **square roots** (perfect squares, mixed numbers under
the radical, quotients like √108/√3).

**Problem Solving** — arithmetic series, powers of 4, divisibility & digit
puzzles, "add to numerator & denominator" puzzles, work-rate, average-speed
(round-trip), **fraction-of-a-group** word problems, **percent-overlap** club
problems, and **geometry** area fractions.

The answer box is forgiving: fractions (`5/8`), mixed numbers (`1 1/12`),
powers (`2^7`), percents (`85%`), and algebraic expressions (`27x + 63`,
typed in any equivalent form) are all accepted, and units like `dogs`/`mph`/`$`
are ignored.

## Rewards to keep practice fun
- ⭐ **Stars** for every correct answer, with **combo bonuses** for answer streaks
- 🔥 **Combo meter** during the test (3+ in a row triggers extra stars & confetti)
- 📅 **Pick-a-day** planner (Day 1–10) with a countdown to the test (July 27)
- 🏅 **XP & levels** with a progress bar
- 🎖️ **Badges** (First Test, Perfect Score, streak milestones, Sharp, Combo x5, Level 5)
- 🦊 **Choose-your-buddy** mascot, animated floating-math background, difficulty
  dots per question, and color-coded topic tags
- 🎊 **Confetti** and encouraging messages, plus a full review at the end

> Tip: Wrong answers show a hint and the correct solution to learn from each one.
